# Al'Fana Wal'Baqa Quiz

**Live site:** https://ashik-mangalan.github.io/Baraqiyya-quiz/

Timed quiz by Team Baraqiyya for Aslami Fest 2K26 (IBDA Exhibition, Daruswalah Islamic Academy, Karamoola, Mukkam).

- 50-question bank, 25 per round (15 Islamic/Arabic + 10 general)
- 15 seconds per question, speed bonus
- Shared leaderboard (Firebase Realtime Database)

Single file: `index.html`. Turn on GitHub Pages (Settings > Pages > Deploy from branch > main / root) to get a public link.
